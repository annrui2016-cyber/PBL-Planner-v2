# AI 中文 PBL 智能设计助手 (AI PBL Planner for Chinese Classes)

这是一个专为阿联酋中文老师设计的轻量级教学辅助工具。通过输入简单的教学参数，AI 将自动生成符合阿联酋本土文化背景、对标 HSK 级别的项目化学习（PBL）教学方案。

## 🌟 核心功能
- **智能生成方案**：一键生成包括驱动问题、学习目标、项目步骤在内的完整 PBL 计划。
- **HSK 级别对标**：严格控制语言难度，确保词汇和句型适合学生的中文水平。
- **阿联酋文化融合**：方案可自动加入本地文化元素（如 Majlis, Kandura, 中阿文化日等）。
- **语言支架支持**：提供中、英、阿三语词汇对照和展示模板。

## 🛠️ 如何使用
1. **获取 API Key**：你需要拥有一个 OpenAI 或兼容平台的 API Key。
2. **输入参数**：在网页中填写年级、学生中文水平（如 HSK 1）、单元主题及核心词汇。
3. **点击生成**：AI 将在几秒钟内为你提供详细的教学设计。
4. **复制修改**：根据实际课堂情况，对生成的方案进行微调。

## 🔒 关于 API Key 安全性
- 本工具为**纯前端应用**，你的 API Key 仅保存在你的浏览器本地，不会上传到任何服务器。
- 为了安全起见，建议在使用完毕后刷新页面，或者使用具有额度限制的 API Key。

## 📁 项目结构
- `index.html`: 核心代码文件，包含了 UI 界面和 AI 调用逻辑。

## 🇦🇪 本地化支持
本助手在 Prompt 设计中特别加入了对阿联酋教育部（MoE）教学要求的理解，旨在帮助老师们更轻松地实施 Project-Based Learning。
